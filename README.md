# 🎨 Dribbble Clone — Design Inspiration Website

A frontend recreation of Dribbble's design inspiration homepage, built using **HTML5 and CSS3**. This project focuses on creating a clean, modern UI with a navigation bar, hero section, search bar, design gallery, hover effects, animated logo carousel, and footer.

The goal of this project was to improve my frontend development skills by recreating a real-world website layout and practicing modern CSS techniques.

## ✨ Features

- **Navigation Bar:** Clean navigation layout with menu items and sign-up/login buttons.
- **Hero Section:** Large heading, descriptive text, and a search bar inspired by Dribbble.
- **Trending Searches:** Quick-access buttons for popular design categories.
- **Design Gallery:** Grid layout displaying multiple design cards with images and videos.
- **Hover Effects:** Animated overlays that reveal design titles and action buttons when hovering over gallery cards.
- **Designer Information:** Profile logos, designer labels, PRO badges, and sample like/view counts.
- **Category Navigation:** Design categories such as Branding, Illustration, Mobile, Typography, and Web Design.
- **Animated Logo Carousel:** Continuously scrolling logos using CSS keyframe animations.
- **Custom Typography:** Google Fonts integration and locally loaded icon font.
- **Footer Section:** Navigation links, social media icons, copyright information, and additional links.

## 🛠️ Technologies & Skills Used

### HTML5
- Semantic HTML structure using `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`.
- Organized reusable card structures.
- Working with images, videos, buttons, and links.
- Using descriptive class names to connect HTML elements with CSS.
- Adding accessibility-related attributes such as `alt` and `aria-label`.

### CSS3
- **Flexbox:** Aligning navigation items, buttons, card details, and footer elements.
- **CSS Grid:** Creating a multi-column design gallery.
- **Positioning:** Using `relative` and `absolute` positioning for image overlays.
- **Transitions:** Creating smooth hover animations.
- **Keyframes:** Building a blinking cursor and continuously scrolling logo carousel.
- **Transforms:** Animating overlays with `translateY()` and rotating search icons.
- **Gradients:** Creating dark image overlays and fading edges around the logo carousel.
- **Typography:** Styling headings with Cormorant Garamond and configuring custom fonts.
- **Object Fit:** Maintaining image and video proportions inside gallery cards.
- **Spacing & Layout:** Applying margin, padding, gap, width, height, and box-sizing.
- **Reusable CSS Classes:** Maintaining consistent styling across repeated components.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure the `image` folder contains the required assets.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No framework, package installation, or build process is required.
